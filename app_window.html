Fortnite keys

The key you use to interact in Fortnite (F by default). Traits and Potion Grab press this key, and fishing also watches for it in the key prompts. Match it to your Fortnite keybind.

Hotkeys work while you're in the game

Click Change, then press the new key (Esc cancels). If another action already uses that key, the two swap. Small keyboard with no Insert, Page Up or arrow keys? Set these to keys you have.

Keys the game needs can't be used: the fishing letters, your Interact key (F), W A S D, Space, Enter and Esc. The arrow keys can only be used for the menu keys. Hotkeys are switched off while this window is in front, so typing here never triggers them.
